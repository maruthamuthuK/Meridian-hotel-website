# 🏨 Hotel Booking Website

A responsive Hotel Booking Website built using **HTML, CSS, and JavaScript**. The website provides a modern and user-friendly interface for browsing hotel rooms, viewing amenities, and making booking inquiries.

## 🚀 Features

* Responsive design for desktop, tablet, and mobile devices
* Modern navigation bar
* Attractive homepage with hotel information
* Room categories with images and details
* Hotel amenities section
* Booking form
* Contact section
* Smooth scrolling
* JavaScript alerts and interactive features

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
